토큰을 많이 써도 되니, 전체 코드를 하나하나 상세하게 보고 개선할 점이 있는지 아래를 판단해라.
1. 개발자 관점 : 코드 품질, 아키텍처, 성능 등 (백엔드/프론트엔드)
2. 디자이너 관점 : UI/UX 품질, 사용자 경험, 컴포넌트 위치 및 페이지 구성 등
3. PM 관점 : 서비스를 퀀트트레이더들에게 잘 팔기 위해서 더 필요한 것
4. 퀀트 트레이더 관점 : 제대로 된 분석이 되어있는지, 모델은 제대로 되어있는지, 전략과 같은 방법론은 잘 되어있는지 등

내가 등으로 끝나게 표시한 것은 저것 말고도 더 생각해서 추가적으로 부문들에 대해 더 찾아보거나 더 생각해서 답하라는 것이다. 저 위에 써준 것만 하지말고.

자 이제 다 분석해서 나한테 보고해라.
