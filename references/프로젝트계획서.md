# UPquant: 업비트 KRW 마켓 암호화폐 분석 대시보드 — 프로젝트 계획서 (적용본)

> ✅ = 적용 완료, 🔜 = 예정.

---

## 1. 프로젝트 개요 (수집할 자료)

UPquant는 국내 최대 암호화폐 거래소 **업비트(Upbit)의 Open API**를 활용해 KRW 마켓 시세 데이터를 수집·가공하고, 이를 시각화한 웹 대시보드입니다. 단순 조회를 넘어 **카테고리 분석 · 종목 비교 · 전략 백테스트 · 조건 스크리닝**까지 제공합니다.

수집·활용하는 데이터 (모두 업비트 **시세(Quotation) REST API**, 인증 불필요):

| 데이터 | 엔드포인트 | 상태 |
|--------|-----------|------|
| 마켓 목록 + 한글명 | `/v1/market/all` | ✅ |
| 현재가(전일 대비 등락률·24h 거래대금·52주 고저) | `/v1/ticker` | ✅ |
| 캔들 OHLCV (분/일/주/월) | `/v1/candles/{minutes/{unit}\|days\|weeks\|months}` | ✅ |
| 호가 | `/v1/orderbook` | ✅ |
| 체결 내역 | `/v1/trades/ticks` | ✅ |
| 7일 등락률·스파크라인 | 일봉 캔들에서 파생 | ✅ |
| 실시간 시세 (WebSocket) | `wss://api.upbit.com/websocket/v1` | 🔜 |

> 원본 계획의 "Redis 캐싱"은 외부 의존성 없는 **인메모리 TTL 캐시(stale-while-revalidate)** 로 먼저 구현했고, 분산 캐시(Redis)는 추후 과제로 둡니다.

## 4. 기술 스택 & 아키텍처

**백엔드 (Python)** — FastAPI · httpx(동기) · pydantic · uvicorn
**프론트엔드 (JavaScript)** — React 19 + Vite · react-router-dom v7 · axios · recharts v3 · lightweight-charts v5 · Tailwind CSS v4

```
[React SPA :5173]  pages → hooks → api(axios)
        │  HTTP /api/* (X-Request-Id)
        ▼
[FastAPI :8000]   routers → services(+캐시) → clients(httpx)
        │  REST 시세 호출 (스로틀·재시도·로깅)
        ▼
[Upbit Open API]  api.upbit.com/v1
```

계층은 Spring과 유사하게 `routers(≈Controller) → services(≈Service) → clients(≈Repository)`로 단방향 의존합니다.

## 5. 적용된 핵심 구현

- **실 업비트 연동** ✅ — 시세 5종 엔드포인트를 동기 httpx 클라이언트로 호출. 분석 유니버스는 **KRW 마켓 전체(~261종, `config.USE_ALL_KRW_MARKETS`)** 이며 `/market/all`과 교집합으로 검증해 상장폐지 종목 자동 제외(예: MATIC→POL). 코인↔카테고리 수동 매핑은 15종(`MARKET_CATEGORIES`)에만 존재.
- **캐싱(stale-while-revalidate + single-flight)** ✅ — 만료돼도 옛 값을 즉시 반환하고 백그라운드 1스레드만 갱신. 일봉은 종목별 200개를 한 번 받아 슬라이스 공유(상관관계 ~1800ms→~5ms). 부팅 시 **동기 프리페치**(tickers+coin_stats 워밍 후 기동)로 첫 사용자 콜드까지 제거.
- **레이트리밋 보호** ✅ — 전역 스로틀(~초당 8회) + 429 백오프 재시도로 시세 API 한도 내 호출.
- **통합 로깅(관측성)** ✅ — `contextvars` 기반 요청 ID(rid)를 axios 인터셉터 · FastAPI 미들웨어 · httpx `event_hook` 3계층 로그에 주입하고 `X-Request-Id` 헤더로 전파(Spring MDC 유사).
- **분석/백테스트** ✅ — 변동성·1개월 수익률·피어슨 상관관계(실 캔들 기반), MA 크로스/RSI 역추세 백테스트(자산 곡선·MDD·승률, 200캔들 초과 페이지네이션).
- **카테고리별 수익률** ⚠️ — 업비트가 코인 카테고리를 제공하지 않아 예시(더미) 데이터 유지.

## 6. 선정 이유

국내 암호화폐 투자자 대부분이 업비트를 사용하지만, 시장 전체 흐름을 한눈에 시각적으로 조망하는 도구(트리맵·상위 등락·종목 비교 등)는 KRW 마켓 기준으로 사실상 부재합니다. 해외에는 Finviz(주식)·CoinGecko(글로벌 코인) 같은 대시보드가 있으나 업비트 KRW 마켓에 특화된 한국어 대시보드는 전무하여, 업비트 Open API로 국내 투자자에 최적화된 시장 대시보드를 직접 구축했습니다.

## 7. 향후 활용 방안 / 로드맵

- **실시간성** 🔜 — WebSocket 시세를 FastAPI가 중계해 호가/체결/현재가 실시간 갱신.
- **카테고리 수익률 실데이터화** 🔜 — 캔들 집계로 섹터별(레이어1·DeFi·밈 등) 자금 흐름 분석.
- **분산 캐시(Redis)** 🔜 — 다중 인스턴스 확장 시.
- **퀀트 활용** — (일부 적용됨) 종목 상관관계·전략 백테스트·조건 스크리닝을 이미 제공. 추후 거래량 급등 알림, 가격 예측 모델·자산배분 전략 연구의 기초 데이터로 활용.
